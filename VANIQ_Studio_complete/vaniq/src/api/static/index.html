One day of Ahirani data work

The agent does the lookups. You make the calls.

Morning

A recording arrives

The file is validated, normalised to 16 kHz mono and split at pauses. Quality flags appear next to each segment. Permission starts as unknown, never assumed.

Midday

A baseline, honestly labelled

The agent proposes running the Marathi or auto-detect setting and waits for approval because audio leaves the machine. The result is stored as an STT baseline experiment, never as Ahirani recognition.

Afternoon

A person writes the reference

The reference box starts empty. Seeing the STT text is opt-in. Corrections from the lexicon are proposals; each is accepted, rejected or modified by a person.

Evening

Only what is permitted leaves

Eligibility is computed from consent, permitted usage and human verification. Unknown or denied permissions never appear in a public export.

Scenes are illustrative of the workflow; they contain no performance figures.

How it works

Three steps, one workspace.

  1. 1

    Record and upload

    Upload or record in the browser. Provenance, speaker pseudonym, declared dialect and consent are captured with the audio.

  2. 2

    Baseline and correct

    Run an STT baseline, then let the dialect lexicon propose corrections. The raw transcript and the provider’s response are always preserved.

  3. 3

    Verify and export

    Reviewers write and verify references. Evaluation reports WER and CER by experiment role. Exports follow the permission rules.

Inside VANIQ

An agent, and an editor for voice data.

Studio

A waveform canvas with segment regions, stacked text tracks (raw, corrected, human reference) and an inspector for dialect, provider output, consent and eligibility.

Agent and skills

Typed, auditable skills run real operations. Safe reads run immediately; STT calls and exports wait for approval. In command mode it says what it cannot do.

Knowledge

Versioned conventions and linguistic references written and approved by people. VANIQ ships none of its own and never invents vocabulary.

Workflows

Chain intake, validation, baseline, review gates, evaluation and export. Every connection is type-checked and carries real data.

What is real

Careful about the language, honest about the limits.

Five things, kept apart

Declared dialect, provider-detected language, writing script, orthographic convention and the human-verified reference are separate fields. Provider output is never relabelled as Ahirani.

Gnani is a baseline provider

Marathi support is documented by the provider. Native Ahirani recognition has not been independently verified, and VANIQ makes no such claim or accuracy figure.

Not built yet

A trained correction model, dialect identification, authentication and a language-model planner. The agent runs in a labelled command mode.
